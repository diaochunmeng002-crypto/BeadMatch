## 已落地

### 彩珠机会屋（BeadProb）

状态：9 个难度、每档 20 道，共 180 道题卡已落地；题库全部通过结构与答案校验。

- 中文名：彩珠机会屋
- 英文名：BeadProb
- 模块：`games/beadprob/`，页面 `/games/beadprob/`
- 题目覆盖可能/不可能/一定、单袋与两袋比较、比例陷阱、相同机会、三颗赛跑、放回后的独立性、多轮累计和不放回
- 每道题都写明线下摸珠动作；页面只出题、给答案和解释
- 普通实验每次放回并摇匀；不放回单独作为第 9 档

当前已做 **9 个难度，每级 20 道，共 180 道**。进一步玩法作为后续方向，
不挤进现在这套以“每道都能摸珠”为核心的系列。

统一流程：

1. 程序说明袋中珠子的组成、问题和摸珠动作。
2. 孩子先在线下摸珠、比较，并口头说出答案。
3. 需要时点“看答案”，对照袋内组成、操作历史或剩余珠子理解规律。
4. 网页不记录逐次结果，也不自动判断孩子答得对不对。

当前难度：

- [x] L1：一定、可能、不可能
- [x] L2：同一袋里比较不同颜色的可能性
- [x] L3：比较两个袋子的可能性
- [x] L4：增减珠子后，可能性如何变化
- [x] L5：总数不同但颜色比例相同时，可能性是否相同
- [x] L6：用“三颗赛跑”实际摸珠，感受多数颜色通常占优但单轮可能被反超
- [x] L7：少量试验会出现波动，不能凭一次结果下结论

后续方向：

- [x] L8：多次试验的结果更接近袋中颜色的比例
- [x] L9：拿出后不放回，下一次可能性如何变化
- [ ] 设计公平或不公平的摸珠游戏
- [ ] 用实验记录验证结论并纠错

题库约束：

- 每级 20 道；每道都写线下摸珠动作。
- 不把某次随机结果当作唯一正确答案，只评价判断、设计和结论。
- L1～L8 每次摸完放回；L9 起加入“不放回”。
- 单只袋子使用 1～3 种颜色、总共 4～12 颗珠子；两只袋子同色合计不超过手头 10 颗。
- L8 的累计记录最多摸到 30 次；其余题使用短次数操作，避免线下负担过重。
