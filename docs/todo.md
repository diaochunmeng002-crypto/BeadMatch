## 待验证玩法

### 摸珠实验室（可能性实验室）

状态：方向已确认，先验证物理摸珠和记录流程。

整体规划是 **10 个难度，每级 10 道，共 100 道**。第一批只做
**L1～L6，共 60 道**；流程稳定后再补 L7～L10。

统一流程：

1. 程序说明袋中珠子的组成和任务。
2. 孩子先判断哪个结果更可能、同样可能或不可能。
3. 孩子实际摸珠，程序负责记录每次结果。
4. 做完 10～20 次后，对照预测和实验数据。
5. 给出规律解释，再进入下一题。

第一批难度：

- [ ] L1：一定、可能、不可能
- [ ] L2：同一袋里比较不同颜色的可能性
- [ ] L3：比较两个袋子的可能性
- [ ] L4：增减珠子后，可能性如何变化
- [ ] L5：总数不同但颜色比例相同时，可能性是否相同
- [ ] L6：少量试验会出现波动，不能凭一次结果下结论

后续难度：

- [ ] L7：多次试验的结果更接近袋中颜色的比例
- [ ] L8：拿出后不放回，下一次可能性如何变化
- [ ] L9：设计公平或不公平的摸珠游戏
- [ ] L10：用实验记录验证结论并纠错

题库约束：

- 每级 10 道，混合快速判断、实际实验、方案比较、设计和纠错题。
- 每题控制在一至三分钟，一次实验做 10～20 次。
- 不把某次随机结果当作唯一正确答案，只评价判断、设计和结论。
- L1～L7 每次摸完放回；L8 起加入“不放回”。
- 使用 2～3 种颜色、总共 5～12 颗珠子，避免桌面材料过多。
