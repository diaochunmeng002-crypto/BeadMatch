## 2. 四个阶段

### L1~L5：学会规则

孩子主要是在学习：

> 谁在前面、谁在后面、谁挨着谁、谁在中间。

这个阶段不要搞太复杂。

### L6~L10：学会"组合"

开始加人：**7 人 → 8 人 → 9 人 → 10 人**，同时**第一次出现重复颜色**。

重点是：

> **多个简单线索组合起来，才能得到答案。**

这是真正开始"动脑"的阶段。

### L11~L15：学会"推理"

人数基本稳定在 **10~11 个**，不要疯狂加人。开始提高：

- 推理链长度
- 距离精度
- 区域限制
- 多组关系同时存在
- 重复颜色的区分

例如：

> 红在绿前面，绿在黄前面，黄和蓝隔一个，蓝挨着紫。

孩子需要自己推出一串关系。

### L16~L20：综合挑战

12~13 人已经足够大了。再加到 15、20 人，对 **6~8 岁儿童**意义未必大，
反而容易变成单纯的"记不住"。

所以后面应该增加的是**推理深度，而不是单纯参与者数量**。例如 L20：

> 13 个珠子、5 组重复颜色、10~15 条简单线索，其中只有少数线索直接给位置，
> 大部分需要通过前面的关系逐步推出。

## 4. 各级机制 ↔ 现在支持的记号

题目文件里写中文原句，程序翻译成记号判定。现在认识这些：

| 中文说法 | 记号 | 从哪一级开始用 |
| --- | --- | --- |
| `X 在第 n 个` / `X 在最前面` / `X 在最后` | `X@n` | L1 |
| `X 在 Y 前面` / `X 在 Y 后面` | `X<Y` / `X>Y` | L1 |
| `X 和 Y 挨着` / `X 和 Y 不挨着` | `X~Y` / `X!~Y` | L2 |
| `X 在 Y 和 Z 中间` | `Y..X..Z` | L3 |
| `X 和 Y 中间隔一个` | `X~~Y` | L3 |
| `X 和 Y 中间隔两个` / `相隔三个位置` | `X~2~Y` / `X~3~Y` | L7 |
| `X 在 Y 前面，但不能紧挨着` | `X<Y` + `X!~Y`（一句出两条） | L7 |
| `X 一定在前/后 3 个位置` | `X@<3` / `X@>3` | L7 |
| `X 不能排在第 n 位` | `X!@n` | L7 |
| `两颗 X 挨着`（同色那两颗） | `X~X` | L6 |

**还没支持、后面几级大概会要的**：

| 规划里提到的 | 现在的状态 |
| --- | --- |
| L14「中间区域」（比如"X 在中间三个位置里"） | ❌ 没有；现在只有"前 N / 后 N" |
| L8~L9「相同颜色的**不同个体**」（"两颗红里靠前的那颗"） | ❌ 没有；同色现在按"存在"理解（有一颗满足就算），分不出是哪一颗 |
| L15 多步传递（A>B>C>D） | ✅ 不用新记号，写几句 `X在Y前面` 就行 |
| L11 多条独立关系链 | ✅ 同上，现有记号够 |
| L10+ 多对重复颜色（2~3 对） | ✅ 判定和前端都支持任意多对 |

## 5. ⚠️ 技术预警：珠子到 10 个以上，现在的检查器会跑不动

现在的"检查题库 / 生成唯一解"是**把所有排列枚举一遍**（图省事、绝对可靠）：

| 珠子数 | 排列数 | 现在跑得动吗 |
| --- | --- | --- |
| 6 | 720 | ✅ 毫秒 |
| 7 | 5,040 | ✅ 毫秒 |
| 8 | 40,320 | ✅ 很快 |
| 9 | 362,880 | ✅ 一两秒 |
| 10 | 3,628,800 | ⚠️ 要几秒到几十秒，内存也上去了 |
| 11 | 39,916,800 | ❌ 基本算不动 |
| 12 | 479,001,600 | ❌ |
| 13 | 6,227,020,800 | ❌ |

**所以做到 L10 左右，得先把检查器换成"按线索剪枝的搜索"**（回溯 + 约束传播），
否则 L11 往后"出题时验证唯一解"这一步就没法做了。这是**换算法**，不是加功能，
接口和题目文件都不用动。
